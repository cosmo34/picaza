NUMERS is not on the App Store. Install iPhone from Safari, Mac by downloading the archive.

Install on iPhone

  1. Open the NUMERS page in Safari (not Chrome).
  2. Tap Register this iPhone and install the signed profile (Settings → General → VPN & Device Management → Downloaded Profile).
  3. The device identifier is sent to Picaza. You can then delete the profile.
  4. Once the device is added, tap Install on iPhone, then trust the developer in Settings → General → VPN & Device Management.

Install on Mac

Download the archive from the product page, unzip, move NUMERS to Applications. On first launch, allow the app in Settings → Privacy & Security if macOS blocks it.

Sync

iPhone and Mac must be on, nearby, with Wi‑Fi (or Bluetooth) enabled. Spreadsheets flow from iPhone to Mac.
